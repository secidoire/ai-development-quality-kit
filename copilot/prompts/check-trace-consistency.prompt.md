# トレース整合チェックプロンプト

トレース表、テストファイル一覧、実行結果を照合してください。

機械的に確認する項目:

- 設計項目に検証条件があるか。
- 検証条件にテストIDがあるか。
- テストIDの実体が存在するか。
- 実行結果が対象commitと設計版に対応しているか。
- 未実行、失敗、古い実行結果、孤立テストがあるか。
- 要求変更により、過去にpassした証拠の期待値が陳腐化していないか。

人レビューに回す項目:

- テスト期待値が設計意図を満たすか。
- 責任境界が妥当か。
- 異常系/否定ケース/故障注入の検証力。

ID一致だけで合格とは扱わず、候補リンクと承認済リンクを分けてください。
古い要求でpassした証拠、再実行してfailした証拠、未実行、コード未作成を区別してください。
